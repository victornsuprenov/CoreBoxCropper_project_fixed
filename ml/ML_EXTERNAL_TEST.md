# Внешний тест YOLO

`test_model.py` использует быстрый контекстный режим.

## Логика

1. YOLO один раз обрабатывает исходное изображение.
2. Если найден **один кандидат**, он выбирается сразу. Глобальный `RulerDetector` не запускается.
3. Если найдено **несколько кандидатов**, линейка ищется только локально вокруг каждого кандидата.
4. При необходимости можно добавить локальную проверку после поворота на 90° через `--ruler-rotate`.
5. Четыре полноразмерных прохода по всему изображению больше не выполняются.

## Команда

```powershell
python .\\ml\\test_model.py "C:\\Pictures\\ВЫБОРКА" --weights "C:\\path\\best.pt"
```

Для дополнительной проверки нестандартной ориентации:

```powershell
python .\\ml\\test_model.py "C:\\Pictures\\ВЫБОРКА" --weights "C:\\path\\best.pt" --ruler-rotate
```

Для сохранения bbox-crop:

```powershell
python .\\ml\\test_model.py "C:\\Pictures\\ВЫБОРКА" --weights "C:\\path\\best.pt" --save-crops
```

## Результаты

По умолчанию создаётся:

- `_ml_test_fast\\predictions` — визуализация кандидатов;
- `_ml_test_fast\\report.csv` — пофайловая статистика;
- `_ml_test_fast\\summary.txt` — итоговая статистика скорости.

`--local-ruler-max-dim` ограничивает разрешение локального CV-поиска; по умолчанию 1800 px.

Текущий тест — диагностический и не изменяет `best.pt`, модель или production-алгоритм.
