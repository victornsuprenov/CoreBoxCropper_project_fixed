# Разметка ML — 4 точки

В редакторе разметки для `target_corebox` теперь используется точная четырёхточечная область: `P1=ЛВ`, `P2=ПВ`, `P3=ПН`, `P4=ЛН`.

## Управление

- Колесо мыши: плавное приближение/отдаление с привязкой к курсору.
- Средняя кнопка мыши + перетаскивание: панорамирование при увеличении.
- `0`: вписать изображение в окно.
- `1`: масштаб 1:1.
- `+` / `-`: изменить масштаб.
- Точки сделаны компактными; активная точка подсвечивается. Центровочные линии помогают точно попасть в нужный пиксель.

## Производительность

Большие фотографии не масштабируются целиком при каждом движении точки. Редактор рендерит только видимую область изображения, а перерисовка во время перетаскивания объединяется через `after_idle`. Загрузка исходного изображения вынесена в фоновый поток, поэтому окно Tkinter не должно зависать на декодировании больших файлов.

## Сохранение

Точные 4 точки сохраняются в `annotations.json`. Для совместимости с текущим YOLO-пайплайном автоматически записывается tight axis-aligned bbox в `labels/<stem>.txt`.

Для обучения V3 keypoint-модели используйте `ml/prepare_keypoint_training.py`.
Он преобразует эти же четыре точки в Ultralytics Pose format без повторной
разметки. Порядок точек фиксирован: `ЛВ, ПВ, ПН, ЛН`.

После кнопки «Очистить точки» можно поставить точки по одной: каждый щелчок
добавляет следующую точку, а линия строится автоматически. Если уже есть
четыре точки, перетаскивание внутри рамки двигает всю рамку; отдельные маркеры
по-прежнему можно уточнять отдельно.
