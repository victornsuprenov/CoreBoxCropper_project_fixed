# CoreBoxCropper

Локальное Windows-приложение для автоматического выделения **одного 3-ячеечного ящика с керном и связанной с ним геологической линейки**.

## Что изменено в этой версии

### Детектор 2.0

Ключевое исправление: поиск ящика теперь не зависит от успешного распознавания цветовой шкалы. Сначала формируются кандидаты из четырёх устойчивых продольных реек, а затем они оцениваются по геометрии. Если линейка найдена, используется **граница всей линейки**, а не только граница цветовой шкалы. Это устраняет ситуацию, когда часть линейки ошибочно принимается за правую стенку ящика.

Алгоритм больше не пытается выбрать «самый большой/самый левый прямоугольник». Он работает от устойчивого признака фотографии — **цветной калибровочной шкалы на геологической линейке**:

1. пытается глобально найти цветную шкалу и всю линейку;
2. если линейка найдена, использует её левую границу как якорь;
3. ищет четыре устойчивые продольные границы непосредственно перед линейкой;
4. четыре границы = ровно три ячейки;
5. при слабой/потерянной шкале запускается геометрический fallback и выбирается наиболее правдоподобный центральный 3-ячеечный кандидат;
6. проверяет регулярность ширины ячеек;
7. проверяет характерное высокое/узкое соотношение сторон ящика;
8. формирует crop как `ящик + вся линейка`;
9. вертикально ограничивает линейку границами выбранного ящика, поэтому пол и посторонние области сверху/снизу не попадают в результат.

Это специально сделано под типовую серию геологических фотографий из проекта.

## Важное правило линейки

В итоговый crop должна попадать вся рабочая часть линейки:

- цветовая шкала;
- деления с шагом 10 см;
- числовые отметки;
- белые информационные бумажки/наклейки.

OCR для этого не требуется: задача алгоритма — правильно включить всю геометрическую область линейки в crop.

Дополнительно для выбора ящика используется слабый визуальный признак верхней
зоны: тёмные подписи/чернила на светлом фоне. Алгоритм не распознаёт текст,
а использует признак только как дополнительный фактор и, когда он подтверждён,
слегка расширяет верхнюю границу crop, чтобы не обрезать эти подписи.

## GUI

Можно выбрать:

- целую папку с фотографиями;
- сразу несколько фотографий через `Ctrl`/`Shift`.

Есть массовая обработка, прогресс, статистика, предпросмотр и ручная коррекция.

В списке фотографий можно выбирать снимки по одному, переключаться кнопками
`Предыдущее` / `Следующее` и для каждого сразу видеть область, которую выбрал
алгоритм. Кнопка `Ошибки / журнал` открывает копируемый журнал GUI и обработки.

Кнопки:

- `Выбрать папку`;
- `Выбрать файлы`;
- `Обработать все выбранные`;
- `Проверить выбранное фото`;
- `Указать область вручную`;
- `Ошибки / журнал`.

Результаты сохраняются с исходным именем файла (без суффикса `_crop`) в
выбранную папку результата.

## Проверка после исправления

На трёх эталонных фотографиях из `attached_assets` детектор должен находить именно 3-ячеечный ящик перед линейкой. В текущей версии проверка проекта проходит командой:

```powershell
pytest -q
```

Ожидаемый результат: все тесты проходят.

## VBA

Excel запускает готовый EXE через CLI. Внутренний Computer Vision от VBA не зависит.

Пример:

```vb
Dim shell As Object
Dim command As String
Set shell = CreateObject("WScript.Shell")
command = """C:\Program Files\CoreBoxCropper\CoreBoxCropper.exe""" & _
          " --input " & QuoteArg(inputPath) & _
          " --output " & QuoteArg(outputPath) & _
          " --json --no-gui"
shell.Run command, 0, True

Function QuoteArg(ByVal value As String) As String
    QuoteArg = """" & Replace(value, """" , """""") & """"
End Function
```

## Сборка EXE

Сначала создать окружение и установить зависимости:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Затем:

```powershell
.\build.bat
```

Production-режим сборки — PyInstaller `onedir`. Это предпочтительнее для первой стабильной версии: проще диагностировать проблемы OpenCV/Pillow и быстрее запускать приложение.

После успешной сборки:

```text
dist\CoreBoxCropper\CoreBoxCropper.exe
```

## Production ML pipeline

При наличии Ultralytics и весов приложение использует быстрый маршрут:

```text
YOLO corebox_v2-2 -> выбор target -> локальный ROI refinement -> 4 угла -> perspective crop
                    | нет detection
                    v
                legacy OpenCV fallback
```

Поиск линейки выполняется только внутри выбранного ROI. Глобальный legacy
OpenCV-поиск сохраняется только как compatibility fallback, когда ML-стек или
веса недоступны. Regression-проверка старых кадров запускается так:

```powershell
python .\ml\regression_test.py .\attached_assets
```

Отчёт сохраняется в `_regression_report.json` внутри указанной папки.
